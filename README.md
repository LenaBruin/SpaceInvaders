Building the project.
1. Download the zip file
2. Extract the zip file
3. Open the SpaceInvaders folder in whatever coding app used (such as studio visual code)
4. Go to the build button or press ctrl+Shift+b to build the project

Running the application.
1. Download the zip file
2. Extract the zip file
3. Open the Main.java file in whatever coding app used (such as visual studio code), located in the SpaceInvaders/src/game folder
4. Run the file

Any required setup or dependencies.
No additional setup is required. Files depend on each other so editing or moving files will cause issues.
